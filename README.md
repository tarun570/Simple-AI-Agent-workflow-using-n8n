 # 🚀 Just Built a Simple AI Automation in n8n!

Today I created a basic AI chat workflow in n8n that automatically replies when a message is received.
Here’s what it does:

💬 Triggers when a chat message arrives

🤖 Sends the message to an AI Agent

🧠 Uses Simple Memory to remember context

🔍 Uses OpenAI Chat Model to generate smart replies

🔁 Automatically sends the response back

It's a simple setup — but it's the foundation for advanced bots like:
✨ WhatsApp replies
✨ Telegram or website chatbots
✨ Customer support AI
✨ Automated lead engagement
